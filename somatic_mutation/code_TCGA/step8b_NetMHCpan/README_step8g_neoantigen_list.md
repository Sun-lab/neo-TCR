# Candidate neoantigen list (step8g)

Generated by `step8g_neoantigen_list.R`. Starting from the mutation × HLA carrier-
enrichment table (step8d), we keep (mutation, HLA) pairs where the HLA-I allele
presents ≥1 mutated neo-peptide of the mutation **and** the allele's normalized
frequency in carriers (E) exceeds 0.05. One row per (mutation, HLA) pair → a
mutation presented by several enriched alleles appears on several rows.

Two files are written:

- `step8g_neoantigen_list.tsv` — the candidate list (columns below).
- `step8g_neoantigen_list_TCR.tsv` — the same rows plus the associated TCRs and their
  p-values (`n_TCRA`, `n_TCRB`, `TCRA`, `TCRB`, `min_pval_TCRA`, `min_pval_TCRB`,
  `min_TCR_pval`), where each TCR is formatted `CDR3(p=…)`.

## Columns of `step8g_neoantigen_list.tsv`

| column | description |
|---|---|
| `key` | genomic mutation key, `GENE:chr:pos:ref:alt` (e.g. `SMC2:9:106885501:A:-`). |
| `mutation` | protein-level label, `GENE:HGVSp_Short` (e.g. `SMC2:T751Pfs*9`). |
| `HLA` | the presenting HLA-I allele (e.g. `A02:01`). |
| `n_neopeptides` | number of mutated neo-peptides of this mutation that the allele presents. |
| `carrier_freq` | frequency of the HLA allele among the mutation's carriers. |
| `norm_HLA_freq_in_carriers` | E = carrier allele frequency − background allele frequency (the >0.05 filter; how enriched the allele is among carriers). |
| `pop_freq_TCGA` | **total number of patients carrying the mutation** in the TCGA cohort (a count, e.g. `15`). |
| `pop_freq_by_cancer` | per-cancer-type breakdown of carriers, `n_carrier/n_total/CANCER`, sorted by carrier count descending, `;`-joined (e.g. `7/436/STAD;3/371/COAD;…`). `n_total` is the number of cohort patients of that cancer type. |
| `peptide_i`, `mut_pos_i`, `EL_rank_i` | the presented mutant neo-peptides for this (mutation, HLA) pair, one triplet per peptide (`i = 1, 2, …`), ordered by EL %rank (strongest binder = `peptide_1`). See below. Trailing triplets are empty when the pair has fewer peptides; the number of filled triplets equals `n_neopeptides`. |

### About `pop_freq_TCGA` and the denominators

Carrier counts come from `~/research/data/TCR/TCGA/_processed_data/mutation_freq_geq_5.tsv`
(one row per patient × mutation, for mutations seen in ≥5 patients). The cohort they
were tabulated over is the **10,042 TCGA patients** in
`sample_info_mutations.tsv` — i.e. all patients with somatic-mutation calls, after
excluding patients annotated with multiple cancer types. This is the **full mutation
cohort, before any of the downstream filtering** applied in the association analysis
(e.g. before intersecting with TCR data). `pop_freq_TCGA` is a raw carrier count out of
this **N_total = 10,042**; divide by 10,042 to get a frequency.

In `pop_freq_by_cancer`, the per-cancer-type denominators are the patient counts of
each cancer type within the same 10,042-patient cohort (BRCA 1004, LUAD 558, UCEC 511,
…), so the per-cancer carrier counts sum to `pop_freq_TCGA`.

### About the presented peptides (`peptide_i` / `mut_pos_i` / `EL_rank_i`)

Source: NetMHCpan 4.1b HLA-I output in `~/research/data/TCR/TCGA/_results/netMHC/`
(`*_mut_HLA_A_B.xls`, `*_mut_HLA_C.xls`, and the matching wild-type `*_ref_*`). These
are the same files and the same presentation rule used in `step8c`.

- `peptide_i` — amino-acid sequence of the **mutant** neo-peptide (8–11-mer).
- `mut_pos_i` — 1-based position of the mutation **within that peptide**, taken as the
  first residue at which the mutant peptide differs from the aligned wild-type peptide.
  For a missense this is the single substituted residue; for a frameshift / indel it is
  where the novel (out-of-frame) sequence begins.
- `EL_rank_i` — the mutant peptide's eluted-ligand %rank from NetMHCpan (smaller =
  stronger predicted presentation).

A peptide is included only if it is "presented": it overlaps the mutation (mutant ≠
wild-type), its mutant EL %rank < 2, and the mutant EL %rank is better (smaller) than
the wild-type peptide's. Within a (mutation, HLA) pair the peptides are sorted by
EL %rank, so `peptide_1` is the strongest binder. The widest pair here has 3 peptides
(`peptide_1..3`).
