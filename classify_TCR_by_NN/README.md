# Classify TCRs into whether they are from cancer reactive T cells using neural network

The input is the amino acids of the TCR.

The output label is decided by whether the T cell which the TCR comes from has high scores in cancer reactive positive gene signatures and low scores in cancer reactive negative gene signatures, or has scores on the opposite direction.

## Data resource

The TCRs generated by

[data_gene_expression_signature/Zheng_2021/step3c_check_TCR.Rmd](https://github.com/Sun-lab/cancer_reactive_TCR/blob/main/data_gene_expression_signature/Zheng_2021/step3c_check_TCR.Rmd)

## Data processing

Initial exploration to see the cleaness of the data:

[data_exploration.ipynb](https://github.com/Sun-lab/cancer_reactive_TCR/blob/main/classify_TCR_by_NN/data_exploration.ipynb)

Data splitting:

[split_data.ipynb](https://github.com/Sun-lab/cancer_reactive_TCR/blob/main/classify_TCR_by_NN/split_data.ipynb)

The training/validation/test split is done for positive and negative TCRs separately.

The way of splitting the data makes sure that there is no overlap on terms of either alpha chain CDR3 or beta chain CDR3 between any two out of training/validation/test parts for the positive TCRs. The same requirement also holds for negative TCRs.

Certain TCRs are abandoned in order to meet this no overlap requirement. Among positive TCRs, about 68.5%, 15.9% and 14.7% go to training/validation/test, and among negative TCRs, the proportions are about 69.1%, 16.0% and 14.4%.

## Model training

```bash
sc_TCR.py
  	├── sc_TCR_utils/_utils.py
               	   ├──  sc_TCR_utils/data/for_encoders
                   ├──  data_for_model
```
The jobs are submitted using [sc_TCR_freq_cutoff_10000.sh](https://github.com/Sun-lab/cancer_reactive_TCR/blob/main/classify_TCR_by_NN/sc_TCR_freq_cutoff_10000.sh).

Multiple combinations of features, amino acid encoding method, number of CNN layers, and dense layer sizes are considered. Details are listed below.

Six features combinations formed by (alpha chain only, beta chain only, both alpha and beta chain)*(CDR3 only, CDR3 + V gene).

Four amino acid encoding methods, namely one_hot, blosum62, atchley, and pca.

Four dense layer sizes, including (32, 16), (64, 32), (128, 64), and (256, 128), where the number of dense layers is always 2, and in each tuple, the first number corresponds to the first layer and the second corresponds to the second layer.

Two settings of the number of CNN layers, either 1 or 2.

| factor | options |
| --- | --- |
| input feature | (alpha chain only, beta chain only, both alpha and beta chain)*(CDR3 only, CDR3 + V gene) |
| encoding method | one_hot, blosum62, atchley, pca |
| layer sizes | (32, 16), (64, 32), (128, 64), (256, 128) |
| # CNN layers| 1, 2 |
